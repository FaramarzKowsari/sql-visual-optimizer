# SQL Visual Optimizer v1.1.0

## Official Infographic Guidebook Release

Version 1.1.0 expands SQL Visual Optimizer from an interactive browser-first SQL performance laboratory into a more complete educational and scholarly software package.

### Added

- **Inside SQL Visual Optimizer**, an official ten-page A4 infographic guidebook.
- A dedicated guidebook landing page.
- Direct PDF viewing and downloading.
- An embedded PDF reader inside the live React application.
- A Guidebook tab in the primary application navigation.
- Repository documentation for guidebook location, use, and citation.
- Structured metadata for the guidebook as a `Book` and `DigitalDocument`.
- Guidebook URLs in the sitemap and machine-readable project summary.
- Improved Open Graph, citation, and discoverability metadata.

### Fixed

- Added Vite client environment type declarations.
- Fixed TypeScript recognition of `import.meta.env.BASE_URL`.
- Restored successful CI and GitHub Pages deployment after guidebook integration.

### Preserved

- Browser-first deterministic SQL analysis.
- Multi-dialect parsing.
- AST inspection.
- Estimated logical-plan visualization.
- PostgreSQL-compatible EXPLAIN JSON import.
- SQL anti-pattern findings and index hypotheses.
- Optional Gemini BYOK explanations.
- No project-owned paid API or embedded secret.
