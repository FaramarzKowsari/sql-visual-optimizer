# ثبت SQL Visual Optimizer در Google Search Console

## آدرس‌های اصلی

صفحه پروژه:

```text
https://faramarzkowsari.github.io/sql-visual-optimizer/
```

نقشه سایت:

```text
https://faramarzkowsari.github.io/sql-visual-optimizer/sitemap.xml
```

## مسیر پیشنهادی

1. وارد Google Search Console شوید.
2. Property مربوط به `https://faramarzkowsari.github.io/` را انتخاب کنید. این URL-prefix تمام زیرمسیرهای همین آدرس، از جمله پروژه حاضر، را پوشش می‌دهد.
3. از منوی Sitemaps، در بخش Add a new sitemap این مسیر را وارد کنید:

```text
sql-visual-optimizer/sitemap.xml
```

4. Submit را بزنید و منتظر وضعیت Success بمانید.
5. در نوار URL Inspection، آدرس کامل پروژه را وارد کنید.
6. Test live URL را اجرا کنید.
7. در صورت موفق‌بودن Page fetch و Indexing allowed، Request indexing را بزنید.
8. پس از چند روز، وضعیت را در Page indexing و Performance بررسی کنید.

## در صورت نداشتن Property ریشه

یک URL-prefix property برای آدرس زیر بسازید:

```text
https://faramarzkowsari.github.io/
```

برای تأیید مالکیت می‌توانید از HTML tag یا HTML verification file استفاده کنید. فایل یا متاتگ تأیید، اختصاصی حساب Search Console شماست و باید دقیقاً همان چیزی باشد که گوگل نمایش می‌دهد.
